👉 **Live Demo**: [https://aman7739.github.io/portfolio/](https://aman7739.github.io/portfolio/)

---

## 🌟 Key Highlights & Features

- 🎨 **Modern Dark / Light Theme**: Atmospheric ambient background inspired by modern developer cockpits with quick toggle.
- 🎴 **Interactive 3D Card Tilt**: Dynamic perspective tilt on project and certification cards responding to cursor motion.
- 📱 **Fully Responsive Layout**: Hand-crafted CSS Grid and Flexbox layouts optimized for mobile, tablet, and widescreen monitors.
- 📬 **Real-Time Contact Form**: Integrated with EmailJS for instant delivery to Gmail with client-side validation.
- 📜 **Verified Achievements & Certificates**: Embedded viewable credentials from ServiceNow, Open Source Connect Global, GeekStacks, and Internshala.
